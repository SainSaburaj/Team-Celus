📘 How to Upload Opportunity Items?

This page will guide you through uploading opportunity line items using the predefined Excel or CSV template.

⬇ Download Upload Template (.xlsx)

Upload Template Field Specifications

Column Name Description Example
Item Internal ID of the NetSuite item. Refer to the item master or export list. 601
Hours Quantity or service hours for the item. 5
Task Description for the line item. Often includes JIRA ticket number and title. IEGUN-1202 Implement Scheduled Script to Update Expected Receipt Date via ShipEngine Tracking

Reference: Item Internal IDs

Use the following Item Internal IDs when preparing your upload file:

Item Internal ID Item Name
609 001 Customization
610 002 Implementation
611 003 Administration
612 004 Consulting
613 005 Integration
615 007 Theme & Extension

📖 Instructions:

  • Ensure you are using the exact Item Internal ID as in your NetSuite item list.
  • Upload only `.xlsx` or `.csv` files using the upload interface.
  • If you're unsure about an Item ID, contact your admin or download the item list.
  • Each line in the file represents a line in the Opportunity's item sublist.
  • The system will ignore blank lines.
